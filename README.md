## 🌟 Asosiy Imkoniyatlar (Features)

- **70% Amaliyot, 30% Nazariya**: Barcha mavzular murakkab formulalarsiz, hayotiy misollar, animatsion diagrammalar va real kodlar bilan tushuntiriladi.
- **Interaktiv Kod Muharriri (Monaco Editor)**: Sayt ichida to‘liq ishlaydigan VS Code Monaco muharriri, HTML/CSS/JS jonli Preview sandboxi va o‘rnatilgan JavaScript terminali (`console.log`, xatolar va buyruqlar).
- **Gamifikatsiyalangan O‘quvchi Kabineti**:
  - Dasturchi darajalari (Junior -> Junior+ -> Middle -> Senior).
  - To‘plangan ballar (XP) va o‘zlashtirish foizi ko‘rsatkichi.
  - Erishilgan nishonlar va badge'lar tizimi (*Birinchi qadam*, *Test chempioni*, *Izlanuvchi*, *Modul ustasi*, *IT mutaxassisi*).
  - Test natijalari va so‘nggi faollik xronologiyasi.
- **O‘qituvchi Paneli (Teacher Dashboard)**:
  - Sinflar (11-A, 11-B, 11-C) kesimida o‘quvchilar ro‘yxati va statistikasi.
  - Yangi topshiriqlar yaratish va muddat (deadline) belgilash.
  - O‘quvchilarga to‘g‘ridan-to‘g‘ri individual tavsiya va izohlar yuborish.
- **4 ta Katta Modul va Yakuniy MVP Loyihalar**:
  - Modul oxirida GitHub orqali topshiriladigan real capstone loyihalar.
- **To‘liq Dual-Theme (Dark & Light Mode)**:
  - Professional kiber-to‘q ko‘k (Dark Mode) va ko‘zni toliqtirmaydigan nafis oq (Light Mode) rejimlari.
- **100% Moslashuvchan (Responsive)**:
  - Kompyuter, noutbuk, planshet va smartfonlarda qulay interfeys.

## 📚 O‘quv Kursi Strukturasi (36 ta dars)

Platforma o‘quv dasturi 4 ta katta bosqichdan iborat:

### I-BOSQICH: Dasturiy Ta’minot Ishlab Chiqish Asoslari (8 dars)
1. Axborot texnologiyalari ekotizimi va SDLC bosqichlari.
2. Git versiyalar nazorati tizimi va GitHub bilan ishlash.
3. Branching strategiyalari, Pull Request va Code Review madaniyati.
4. Clean Code va SOLID tamoyillari (Single Responsibility, OCP, LSP, ISP, DIP).
5. Factory, Singleton va Observer Design Patterns.
6. REST API arxitekturasi va JSON ma’lumotlar almashinuvi.
7. Dasturchilar jamoasida ishlash va samarali kommunikatsiya.
8. Liderlik, loyihaviy tafakkur va vaqtni boshqarish (Time Management).
*🏆 Modul Loyihasi: Shaxsiy Portfolio veb-saytini yaratish va GitHub Pages-ga joylash.*

### II-BOSQICH: DevOps va Uzluksiz Integratsiya (8 dars)
1. Linux va Unix operatsion tizimlari asoslari.
2. Terminal va Bash buyruqlari bilan ishlash mahorati.
3. SSH xavfsiz protokoli va Nginx veb-serveri.
4. Docker arxitekturasi va konteynerlashtirish tushunchasi.
5. Docker Image yaratish (`Dockerfile`) va Container boshqaruvi.
6. Docker Volume (ma’lumotlarni saqlash) va Docker Network.
7. GitHub Actions yordamida jarayonlarni avtomatlashtirish.
8. CI/CD quvurlari va avtomatlashtirilgan testlash.
*🏆 Modul Loyihasi: Docker konteynerida ishlaydigan to‘liq Web Application.*

### III-BOSQICH: Cloud va Deployment (8 dars)
1. Zamonaviy Deployment tushunchasi va usullari.
2. Muhit o‘zgaruvchilari (Environment Variables) va xavfsizlik.
3. AWS, Microsoft Azure va Google Cloud ekotizimlari.
4. AWS EC2 virtual serverlari, S3 xotirasi va IAM ruxsatlari.
5. Domen sotib olish, DNS yozuvlari (A, CNAME, MX).
6. SSL/TLS sertifikatlari va HTTPS xavfsiz ulanishi.
7. Cloud Security va bulutdagi xavfsizlik qoidalari.
8. Access Control, rollar va ma’lumotlar himoyasi.
*🏆 Modul Loyihasi: Veb-loyihani Cloud serveriga muvaffaqiyatli deploy qilish.*

### IV-BOSQICH: Freelance va Startap (12 dars)
1. Freelance ekotizimi va zamonaviy bozor talablari.
2. Xalqaro darajadagi dasturchi portfoliosini shakllantirish.
3. GitHub faolligi va Case Study tayyorlash sirlari.
4. Real mijozlar bilan muloqot va talablarni aniqlash.
5. Loyihani narxlash, smeta tuzish va shartnoma kelishuvi.
6. Startap tushunchasi va biznes g‘oyani topish.
7. MVP (Minimum Viable Product) yaratish strategiyasi.
8. Lean Canvas va Value Proposition Canvas bilan ishlash.
9. Pitch Deck va investorlar uchun taqdimot tayyorlash.
10. Loyihani boshqarish metodologiyalari.
11. Agile, Scrum va Kanban tizimlari.
12. Jira, Trello va ClickUp vositalaridan amaliy foydalanish.
*🏆 Modul Loyihasi: Maktab uchun foydali Startup MVP loyihasi va biznes taqdimoti.*

## 💻 Interaktiv Kod Muharriri & Terminal

Platforma ichida brauzerda to‘g‘ridan-to‘g‘ri ishlovchi xavfsiz sandbox muhiti mavjud:
- **VS Code Monaco Engine**: Syntax highlighting, kodni to‘ldirish va formatlash.
- **Jonli Preview**: HTML va CSS o‘zgarishlarini real vaqtda ko‘rsatish.
- **Interaktiv Terminal**: Kod ichidagi `console.log`, `console.error` va xatoliklarni tutib oluvchi terminal paneli.
- **Buyruqlar qatori**: Terminalning pastki qismida JavaScript ifodalarini jonli sinash imkoniyati.
- **Tayyor Shablonlar**: Boshlang‘ich shablon, Shaxsiy Portfolio, Kalkulyator va Vazifalar ro‘yxati (To-do).

## 🚀 Loyihani Lokal Ishga Tushirish

Loyihani o‘z kompyuteringizda ishga tushirish uchun quyidagi qadamlarni bajaring:

### 1. Repozitoriyni klonlash:
```bash
git clone https://github.com/SarvarSalimov007/AXV-11-sinf.git
cd AXV-11-sinf/it-lab-11
```

### 2. Bog‘liqliklarni o‘rnatish:
```bash
npm install
```

### 3. Dasturchi rejimida ishga tushirish:
```bash
npm run dev
```

Brauzeringizda **[http://localhost:3000](http://localhost:3000)** manzilini oching.

### 4. Ishlab chiqarish (Production build) uchun yig‘ish:
```bash
npm run build
npm run start
```
